- sostituisce l'app su vercel
- imposta url del server
- accoda la decodifica del Qrcode all'host
- salva l'host nel local storage del browser
- testato su IOS

### Installazione
Copiare i file di questa cartella sul vostro hosting web in una cartella dedicata.

### Utilizzo

E' possibile utilizzare la versione su mushborg.it all'ìindirizzo [https://www.mushborg.it/](https://mushborg.it/qrcode). Il client non registra alcun dato propoveniente dal vostro browser. Impostando il vostro servizio locale di Mushborg il client si occuperà di fare da bridge tra la lettura del qr code e la vostra istanza.

### Attenzione 

#### Per hosting su altro server necessita domenio con certificato ssl per l'accesso alla telecamera del dispositivo
